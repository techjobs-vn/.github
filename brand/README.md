# Brand assets

Sources for the images used on the techjobs-vn GitHub org. Edit the HTML, then run `./render.sh` (needs Google Chrome; set `CHROME=` to use another binary; fonts load from Google Fonts, so it needs network).

| Source | Output | Used for |
| --- | --- | --- |
| `banner.html` | `../profile/banner.png` | Header of the org profile README |
| `social-preview.html` | `social-preview.png` | `vn-student-programs` social preview (upload by hand: repo Settings → Social preview, GitHub has no API for it) |
| `logo.png` | | Logo shown in both images (copy of https://techjobs.vn/icon-512.png) |
